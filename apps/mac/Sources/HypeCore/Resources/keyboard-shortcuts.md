# Keyboard Shortcuts

## Views

| Shortcut | Action |
| --- | --- |
| `⌘1` | Slide view |
| `⌘2` | Source view |
| `⌘3` | Light table |

## File

| Shortcut | Action |
| --- | --- |
| `⌘N` | New presentation |
| `⌘O` | Open presentation |
| `⌘S` | Save |
| `⇧⌘S` | Save As |
| `⌘E` | Export as PDF |

## Editing

| Shortcut | Action |
| --- | --- |
| `⌘Z` | Undo |
| `⇧⌘Z` | Redo |
| `⌘B` | Bold selection |
| `⌘I` | Italic selection |
| `⌘U` | Underline selection |
| `⌘+` | Bigger text |
| `⌘-` | Smaller text |
| `⌘0` | Default text size |
| `⌘↩` | New slide |
| `⌘D` | Duplicate slide |
| `⌘⌫` | Delete slide |
| `⌥⌘↑` | Move slide earlier |
| `⌥⌘↓` | Move slide later |
| `⌃⌘F` | Toggle fullscreen presenter |

## Format menu

| Shortcut | Action |
| --- | --- |
| `⌥⌘1` | Heading |
| `⌥⌘2` | Bulleted list |
| `⌥⌘3` | Numbered list |
| `⌥⌘4` | Quote |
| `⌥⌘5` | Code block |
| `⌥⌘6` | Table |
| `⌥⌘N` | Speaker note |
| `⌥⌘C` | Inline code |
| `⇧⌘M` | Insert picture or video |

## AI

| Shortcut | Action |
| --- | --- |
| `⌘J` | Ask AI about this slide |
| `⌥⌘R` | Rewrite whole deck |
| `⌥⌘K` | Suggest speaker notes |
| `⌥⌘I` | Generate a picture |
| `⇧⌘G` | Generate a presentation |

## Presenter

| Key | Action |
| --- | --- |
| `→`, `↓`, `Space` | Next slide |
| `←`, `↑` | Previous slide |
| `Home` | First slide |
| `End` | Last slide |
| `Esc` | End presentation |
| `F` | Toggle fullscreen |
| `G` | Slide grid |
