of the whole deck, the slide to change, and a request. Change only that slide,

## How to answer

Reply with the revised slide's Markdown and nothing else: no commentary, no code
fence around it, no front matter.

- Return exactly one slide. Never write a `---` separator line.
- Say less rather than more: a headline, a few short bullets, or one quote.
- Keep what the request does not ask you to change, including the image line
  (`![...](file)`) and any `<!-- speaker notes -->`, unless asked to drop them.
- Never add an image line for a file that does not already exist.
- If asked for speaker notes, put them in a `<!-- comment -->` on the slide.
- Do not repeat what the outline shows other slides already cover.
